> 调研时间：2026-10。来源：linux.do 等社区热点 + 5 篇优秀中文技术文章的结构分析。
> 写作规范见 [`writing-guide.md`](./writing-guide.md)。

## 一、总原则（用户明确要求）

1. **不要全站只写 Cloudflare**。Cloudflare 好写，但一个方向最多占整体的六分之一。
2. **优先写「这个博客本身的技术实现」**：本站经过大量定制，这些内容别处抄不到，而且都能在线上验证。
3. 一题一文，不拆碎；不写「50 字就说完」的小技巧。
4. 每篇关键处必须有截图，且截图必须是自己实测的。
5. 同一批文章选题要分散，不要连着几篇同一方向。

## 四、明确不做的选题

1. **平台功能巡礼 / 官方文档搬运**（如《Cloudflare 免费套餐完整介绍》）——没有实测、没有取舍。
2. **主题安装配置教程**（README 已覆盖，写不到 800 字）。
3. **命令速查表**（pnpm / Git / curl 常用命令之类）——典型低价值短贴。
4. **VPS / 机场推荐**——需要真金白银且易写成 AFF 软文，损害可信度。
5. **重装系统、装机全流程**——与站点技术纵深无关，信息密度低。
